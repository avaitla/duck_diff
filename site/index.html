🦆 duck_diff

Two tables, maybe two entirely different databases, one question: are these actually the same rows? duck_diff is a DuckDB extension that answers per key and per column — across any pair of systems DuckDB can reach: Postgres, MySQL, ClickHouse, BigQuery, Snowflake, Iceberg, Delta, MongoDB, plain Parquet files, and more. Everything below runs locally in the duckdb CLI; your data never leaves your pond.

Since duck_diff is deterministic, it's a validation step Claude can run in loops (i.e. with Claude Code's /goal — examples below): safely refactor a model, optimize a slow query, or transpile SQL to another dialect, checking its own correctness after every change and stopping only when the diff comes back clean.

        Type promotion (upcast_types)Reconcile differing types — MySQL INT vs BigQuery INT64, Postgres NUMERIC vs Snowflake NUMBER — on their common super-type. Auto-enabled for cross-system pairs.

      

        NULL = '' (null_equals_empty)Treat NULL and empty string as equal for text columns — common after CSV round-trips.

    

    

      

        Numeric tolerance (numeric_tolerance)Floating-point values rarely survive two engines bit-for-bit. Treat |left − right| ≤ ε as identical.
